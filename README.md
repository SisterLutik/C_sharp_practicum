# Events API

API для управления событиями. Поддерживает полный CRUD и частичное обновление событий.

## Требования

- .NET 6.0 или выше

## Запуск проекта

```bash
dotnet restore
dotnet run
```

После запуска откройте в браузере:

```
https://localhost:5001/swagger
```

## Эндпоинты

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | `/api/events` | Получить все события |
| GET | `/api/events/{id}` | Получить событие по ID |
| POST | `/api/events` | Создать событие |
| PATCH | `/api/events/{id}` | Частичное обновление |
| DELETE | `/api/events/{id}` | Удалить событие |

## Примеры запросов

### GET /api/events

**Ответ:**
```json
[
  {
    "id": 1,
    "title": "Интенсив по ловле жуков",
    "description": "Увлекательный аттракцион",
    "startAt": "2025-06-12T10:00:00",
    "endAt": "2025-06-14T18:00:00"
  }
]
```

### GET /api/events/1

**Ответ (200):**
```json
{
  "id": 1,
  "title": "Интенсив по ловле жуков",
  "description": "Увлекательный аттракцион",
  "startAt": "2025-06-12T10:00:00",
  "endAt": "2025-06-14T18:00:00"
}
```

**Ошибка (404):**
```json
{
  "message": "Событие с id 999 не найдено"
}
```

### POST /api/events

**Запрос:**
```json
{
  "title": "Новая конференция",
  "description": "Описание конференции",
  "startAt": "2025-07-01T10:00:00",
  "endAt": "2025-07-01T18:00:00"
}
```

**Ответ (201):**
```json
{
  "id": 3,
  "title": "Новая конференция",
  "description": "Описание конференции",
  "startAt": "2025-07-01T10:00:00",
  "endAt": "2025-07-01T18:00:00"
}
```

### PATCH /api/events/1

**Запрос:**
```json
{
  "title": "Новое название",
  "endAt": "2025-12-31T18:00:00"
}
```

**Ответ (200):**
```json
{
  "message": "Событие успешно обновлено",
  "updatedFields": ["Title", "EndAt"],
  "event": {
    "id": 1,
    "title": "Новое название",
    "description": "Старое описание",
    "startAt": "2025-06-12T10:00:00",
    "endAt": "2025-12-31T18:00:00"
  }
}
```

### DELETE /api/events/1

**Ответ:** `204 No Content`

## Валидация

| Поле | Правило |
|------|---------|
| Title | Обязательное |
| StartAt | Обязательное |
| EndAt | Обязательное, должно быть позже StartAt |

## Технологии

- ASP.NET Core 6.0
- Swagger / OpenAPI
- C# 10.0
