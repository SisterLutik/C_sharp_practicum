# Events API

API для управления событиями. Поддерживает полный CRUD, фильтрацию, пагинацию и глобальную обработку ошибок.

## Требования

- .NET 8.0 или выше
- Любая ОС (Windows, Linux, macOS)

## Запуск проекта

1. Восстановите зависимости:
```bash
dotnet restore
```

2. Запустите приложение:
```bash
dotnet run
```

3. Откройте Swagger UI:
```
https://localhost:5286/swagger
```

## Запуск тестов

```bash
dotnet test
```

## Эндпоинты

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | `/api/events` | Получить все события с фильтрацией и пагинацией |
| GET | `/api/events/{id}` | Получить событие по ID |
| POST | `/api/events` | Создать событие |
| PUT | `/api/events/{id}` | Полностью обновить событие |
| DELETE | `/api/events/{id}` | Удалить событие |

## Параметры запроса (GET /api/events)

| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `title` | string | Нет | Поиск по названию (регистронезависимый, частичное совпадение) |
| `from` | DateTime | Нет | События, начинающиеся не раньше указанной даты |
| `to` | DateTime | Нет | События, заканчивающиеся не позже указанной даты |
| `page` | int | Нет (по умолчанию 1) | Номер страницы |
| `pageSize` | int | Нет (по умолчанию 10) | Количество элементов на странице |

## Формат ответа (GET /api/events)

```json
{
    "page": 2,
    "pageSize": 5,
    "totalCount": 12,
    "totalPages": 3,
    "items": [
        {
            "id": 6,
            "title": "Конференция по IT",
            "description": "Описание конференции",
            "startAt": "2025-07-05T10:00:00",
            "endAt": "2025-07-05T18:00:00"
        }
    ]
}
```

## Примеры запросов

### GET /api/events
Возвращает первые 10 событий.

### GET /api/events?title=конференция
Возвращает события, содержащие "конференция" в названии.

### GET /api/events?from=2025-07-01&to=2025-07-31
Возвращает события за июль 2025 года.

### GET /api/events?page=2&pageSize=5
Возвращает вторую страницу по 5 событий на странице.

### GET /api/events?title=конференция&from=2025-07-01&to=2025-07-31&page=1&pageSize=10
Возвращает события по всем фильтрам с пагинацией.

### GET /api/events/1

**Ответ:**
```json
{
    "id": 1,
    "title": "Интенсив по ловле жуков",
    "description": "Увлекательный аттракцион",
    "startAt": "2025-06-12T10:00:00",
    "endAt": "2025-06-14T18:00:00"
}
```

### POST /api/events

**Запрос:**
```json
{
    "title": "Новая конференция",
    "description": "Описание конференции",
    "startAt": "2025-07-01T10:00:00",
    "endAt": "2025-07-01T18:00:00"
}
```

**Ответ (201 Created):**
```json
{
    "id": 3,
    "title": "Новая конференция",
    "description": "Описание конференции",
    "startAt": "2025-07-01T10:00:00",
    "endAt": "2025-07-01T18:00:00"
}
```

### PUT /api/events/1

**Запрос:**
```json
{
    "id": 1,
    "title": "Обновлённое название",
    "description": "Новое описание",
    "startAt": "2025-08-01T10:00:00",
    "endAt": "2025-08-01T20:00:00"
}
```

**Ответ (200 OK):**
```json
{
    "id": 1,
    "title": "Обновлённое название",
    "description": "Новое описание",
    "startAt": "2025-08-01T10:00:00",
    "endAt": "2025-08-01T20:00:00"
}
```

### DELETE /api/events/1

**Ответ:** `204 No Content`

## Формат ответа при ошибках

При возникновении ошибки API возвращает JSON-ответ в формате Problem Details (RFC 7807):

**Пример ошибки валидации (400 Bad Request):**
```json
{
    "status": 400,
    "detail": "EndAt должен быть позже StartAt"
}
```

**Пример ошибки "не найдено" (404 Not Found):**
```json
{
    "status": 404,
    "detail": "Событие с id 999 не найдено"
}
```

**Пример внутренней ошибки (500 Internal Server Error):**
```json
{
    "status": 500,
    "detail": "Произошла непредвиденная ошибка. Попробуйте позже."
}
```

## Коды ответов

| Код | Описание |
|-----|----------|
| 200 | Успешный запрос |
| 201 | Событие создано |
| 204 | Событие удалено (нет содержимого) |
| 400 | Ошибка валидации |
| 404 | Событие не найдено |
| 500 | Внутренняя ошибка сервера |

## Валидация

| Поле | Правило |
|------|---------|
| Title | Обязательное |
| StartAt | Обязательное |
| EndAt | Обязательное, должно быть позже StartAt |
